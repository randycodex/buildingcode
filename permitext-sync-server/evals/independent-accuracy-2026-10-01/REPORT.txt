Main finding
The strongest demonstrated weakness is natural-language evidence discovery and evidence retention, not simply model intelligence. The same 50 source families produced 45 useful correct answers with section references and 31 without them. Expanding searchable current libraries improved the latter to 34, but regressed on 4 previously passing cases. Neither experiment establishes 95% product accuracy.

Changes tested locally
1. Preserve complete short leading provisions when the evidence budget allows them. This recovered operative exceptions/thresholds previously cut off, including bicycle-parking waivers.
2. Extract matched numbered subsections with their parent conditions from large imported chapters. Mark partial sources as incomplete rather than presenting them as complete.
3. Limit heading relevance bonuses to substantive words literally present in the current question. A looser expanded-query variant was rejected after regressions.
4. Keep topic-route coverage advisory behind an evaluation flag. User-pinned passages and direct references retain their obligations.
5. Test broader authorized current-library search behind an evaluation flag. Historical/future editions and explicit scope boundaries remain protected. Mixed results do not justify enabling it in production yet.
6. A separate optional ranking experiment removes heuristic-route precedence and controlling status. Offline inspection did not recover the main missing rules; no paid run was launched for it.

Why failures happen
A useful provision can fail at several stages: its code family is not searched; lexical discovery misses it; a keyword route crowds it out; the evidence budget omits its decisive paragraph; or verification withholds an otherwise answerable response. These need separate diagnostics. Searching more documents alone can increase competing irrelevant material. A verifier pass is not independent proof of correctness: a heldout answer opened with the wrong Yes before giving the opposite rule.

Recommended next implementation
Use a two-stage retrieval pipeline that searches authorized versioned sources broadly, then ranks passages against the actual question before assembling complete operative rules, conditions and exceptions. Measure decisive-text recall, not merely whether a chapter ID appears. Add a bounded retrieval-repair step when the required rule is absent; do not repeatedly rewrite an answer over the same inadequate packet. Preserve correct supported portions and explain the specific unresolved fact or missing authority in ordinary language. Ask only followups that resolve applicability. Keep answer-level citation and contradiction checks, but avoid generic unexplained failure copy.

Version management
Code amendments require a versioned source-update and regression process, not retraining the model on every amendment. Preserve source provenance, publication/effective dates, superseded versions and project code basis. Corpus metadata alone does not establish current legal completeness: the zoning snapshot identifies text through 2026-08-13. A full amendment audit was not performed here.

Limits and unresolved adjudication
This was a curated evaluation graded by the assistant against frozen source keys, separately from the API verifier. It was not blinded professional review and is not a representative sample of all user questions. Official sources were selectively crosschecked; not every imported provision received an external current-version audit. Three heldout cases retained key/source ambiguity: individual-pane versus aggregate window area, and the hub-versus-pipe modifier in PC 802.3.2. Do not turn the latter into an assertion that a flush hub is lawful. Questions inspected during improvement became regression cases, not fresh heldout tests. The named-section heldout result has a naive 95% interval of roughly 86.3–96.6%; related pairs weaken independence. No 95% product claim is justified.

Project-linked workflows, hosted production, browser formatting and contemporary ChatGPT comparisons were not evaluated by this isolated campaign. They require separate acceptance checks and are not implied by these results.
