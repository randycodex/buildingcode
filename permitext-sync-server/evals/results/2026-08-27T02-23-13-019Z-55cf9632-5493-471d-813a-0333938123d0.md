### Permitext answer

No—not as the only permitted method. If the room is used for assembly purposes, has an occupant load of fewer than 75 persons, and is accessory to another occupancy, BC 303.1.3 classifies the room as Group B or as part of that other occupancy. That classification does not eliminate the express option to calculate the room’s plumbing fixtures using the Assembly-occupancy requirements. The Plumbing Code separately confirms that a qualifying assembly-use space with fewer than 75 persons classified as Group B may use the Assembly fixture requirements.

Accordingly, normal Group B fixture requirements are not mandated exclusively for this room; Assembly fixture ratios are a permitted alternative calculation path. The Group B classification is the result for the room—it does not establish that the occupancy to which the room is accessory must itself be Group B.

The supplied evidence does not include Table 403.1, so it cannot establish the actual fixture count or compare the Group B and applicable Assembly ratios. For either path, use the Building Code occupant load; ordinarily split that load equally between sexes, apply each fixture-type ratio, and round fractions up. Approved statistical data may support another sex distribution. The supplied provisions also do not establish whether existing or shared facilities may be credited.

**What the selected evidence establishes**

- Group B classification preserves an Assembly fixture option: An assembly-use room with fewer than 75 occupants that is accessory to another occupancy is classified as Group B or as part of that occupancy. Despite that classification, the number of plumbing fixtures for the room is permitted to be calculated under the requirements for Assembly occupancies.
- The Plumbing Code confirms the Assembly calculation path: Fixtures are generally provided by occupancy type and Table 403.1, with occupant load and occupancy classification determined under the Building Code. The Plumbing Code separately permits Assembly-occupancy fixture calculations for qualifying assembly-use space with fewer than 75 persons classified as Group B.
- Fixture calculation and sex distribution: The total occupant load is ordinarily divided equally between sexes, each applicable Table 403.1 fixture ratio is applied by fixture type, and fractional results are rounded up. For multiple occupancies, fractional results are summed before rounding. Approved statistical data indicating a different sex distribution may be used instead of an equal division.
