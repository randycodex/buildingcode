Each area without fixed seating must have an occupant load no lower than its floor area divided by the Table 1004.1.3 factor for that space’s actual function. Counting only selected movable seats would therefore not establish the required load.

The conference, soft-seating, coffee-break, and lounge portions cannot be reduced by simply treating them as nonsimultaneous. Where different functions have different occupant-load factors, the floor area of each function must be calculated independently. The supplied evidence does not provide an exception allowing nonsimultaneity to omit otherwise usable floor area.

The existing 1:100 documentation may be retained only if it is at least the load produced by the applicable Table 1004.1.3 factors for the actual function areas. A lower-than-table basis requires the commissioner to establish it where actual occupancy will be significantly lower; none is established in the stated facts.
