> Plumbing fixtures shall be provided for the type of occupancy and in the minimum number shown in Table 403.1 . **PC 403.1.1 — canonical section 11910**

> To determine the occupant load of each sex, the total occupant load shall be divided in half. For calculations involving multiple occupancies, such fractional numbers for each occupancy shall first be summed and then rounded up to the next whole number. Fixture calculations in Group B office occupancies shall utilize the total occupant load on a given floor to determine the number of fixtures required for that floor.
> Exception: The total occupant load shall not be required to be divided in half where approved statistical data indicates a distribution of the sexes of other than 50 percent of each sex.

### Permitext answer

Yes. For each fixture type, apply the applicable Table 403.1 ratio to each occupancy’s occupant load for each sex, add the resulting fractional fixture amounts across the B, F, S, and any separately calculated multipurpose-room occupancy, and then round that combined total up to the next whole fixture. Do not round each occupancy’s fractional result first. The default calculation divides total occupant load equally between the sexes, unless approved statistical data supports another distribution.

The multipurpose room may use Assembly plumbing-fixture requirements if it is used for assembly, has an occupant load below 75, and is accessory to another occupancy. If those conditions are met, it is classified as Group B or as part of the principal occupancy, but its fixture count is permitted to be calculated under Assembly requirements. The separately supplied Plumbing Code passage likewise allows Assembly fixture calculations, but for a distinct category: building or nonaccessory tenant assembly space below 75 persons that is classified Group B under the cited Building Code provision. That separate rule is not needed to establish the accessory-room permission.

No final fixture count can be determined from the supplied evidence because Table 403.1 itself, the actual classifications and occupant loads, the room’s Assembly function, and whether it is accessory are not established. If the residential occupancy is Group R-2, the supplied Building Code also has conditional egress occupant-load and classification rules for R-2 accessory spaces; those rules do not change the stated sum-before-rounding method, but their applicability cannot be determined from the facts provided.

**What the selected evidence establishes**

- Sum multiple-occupancy fractions before rounding: For each fixture type, apply the Table 403.1 ratio or ratios to the occupant load of each sex. For multiple occupancies, sum the resulting fractional fixture amounts for each occupancy first, then round the total up to the next whole number. - Fixture requirements depend on Table 403.1 and Building Code inputs: The minimum fixture number is set by occupancy type and Table 403.1. The Plumbing Code directs that occupant load and occupancy classification be determined under the New York City Building Code.
