No—not on the supplied provisions alone. Because the seats are movable rather than fixed, the fixed-seat count method does not apply. Each area without fixed seating must have an occupant load no lower than the area divided by the Table 1004.1.3 factor for that space’s function. Where the floor contains functions with different factors, each function’s area must be calculated independently. Thus, selected movable-seat counts cannot replace the applicable area-based calculation for conference, soft-seating, coffee-break, and lounge areas.

The supplied evidence also does not authorize omitting lounge or break areas merely by characterizing them as nonsimultaneous. Whether and how nonsimultaneous uses may be treated is not established by these passages. For egress, the design occupant load is the largest load computed under the area-based rule, except where a stated permission applies.

A lower basis based on an actual occupant count is available only if the commissioner establishes it where actual occupants will be significantly below the table result. Since no commissioner-established lower basis is identified, it cannot support the proposed reduction. The existing 1:100 documentation may be retained only if, after identifying each actual function and its applicable Table 1004.1.3 factor and calculating each function separately, it is at least the required design load; the supplied evidence does not include the table values needed to determine that comparison.
