No. This NYC Building Code section does not prove that HCR requires a bathroom vanity.

The cited forward-approach provision applies only where a water closet has only a forward approach. It requires specified water-closet clearances and says that a lavatory complying with another section is **permitted** on the rear wall at a stated distance from the water-closet centerline.  Permitted  allows that location; it does not require a lavatory, and it does not require a vanity, cabinet, countertop, or storage.

Separately, within the stated scope of a Type B+NYC dwelling or sleeping unit, the NYC Building Code requires at least one compliant lavatory in each provided toilet or bathing room. That is a NYC Building Code lavatory requirement—not an HCR requirement—and the supplied text does not equate a lavatory with a vanity. The Type B+NYC scope and the forward-approach layout have not been established here.

To determine whether HCR itself requires a vanity, the applicable HCR regulation, program design standard, funding or regulatory agreement, or official agency directive is needed.

**What the selected evidence establishes**

- Forward-approach rule permits, but does not require, a lavatory location: Where only a forward approach is provided to a water closet, the provision requires 66 inches of clearance measured from the rear wall and 48 inches measured from the side wall. This is placement permission, not a mandate to install a lavatory or a vanity.
