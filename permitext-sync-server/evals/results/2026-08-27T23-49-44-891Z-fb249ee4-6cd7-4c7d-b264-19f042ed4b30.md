> Exception: The total occupant load shall not be required to be divided in half where approved statistical data indicates a distribution of the sexes of other than 50 percent of each sex.

### Permitext answer

Yes. For multiple occupancies, apply the applicable Table 403.1 fixture ratio or ratios to each occupancy and each sex, add the resulting fractional requirements, then round the combined result up to the next whole fixture. The default calculation divides the occupant load 50/50 by sex; a different distribution may be used only when approved statistical data supports it. Table 403.1 establishes fixture minimums, while the Building Code determines occupancy classifications and occupant loads.

If the Group B space is in fact an office occupancy, its fixture calculation must use the total occupant load on the given floor. Its actual function remains material because this special rule is limited to Group B office occupancies.

The multipurpose room may use Assembly fixture requirements if it is used for assembly purposes, has an occupant load below 75, and is accessory to another occupancy. In that circumstance, it is classified as Group B or as part of the occupancy to which it is accessory, but its plumbing fixtures may be calculated under the Assembly requirements. The separately supplied PC 403.1 Assembly permission instead applies to a building or nonaccessory tenant space used for assembly by fewer than 75 persons and classified as Group B under the cited Building Code exception; it is not the authority for the potentially accessory room described here.

A final fixture count cannot be determined from the supplied facts. It depends on each room’s actual function and resulting classification, the Building Code occupant loads, the applicable Assembly category and Table 403.1 ratios, whether the multipurpose room is accessory, and the available existing fixtures. The supplied evidence does not establish permission for facilities to be shared among the identified occupancies, so shared use cannot be assumed.

**What the selected evidence establishes**

- Multiple-occupancy fractions are summed before rounding: For each fixture type, apply the applicable Table 403.1 ratio or ratios to the occupant load of each sex. In a multiple-occupancy calculation, sum the fractional results for each occupancy first and then round the combined result up to the next whole number.
- Sex distribution and Group B office calculation: The total occupant load is divided equally between the sexes unless approved statistical data supports a different distribution. For Group B office occupancies, fixture calculations must use the total occupant load on the given floor.
