BC §303.1.3 classifies an accessory assembly room with fewer than 75 occupants as Group B or part of the other occupancy, while separately allowing the number of plumbing fixtures for that room or space to be calculated under the Assembly-occupancy requirements. PC §403.1 repeats the Assembly-calculation permission for a building or nonaccessory tenant space used for assembly purposes by fewer than 75 persons and classified as Group B under the referenced Building Code provision. PC §403.1 generally requires fixtures by occupancy type and minimum quantities in Table 403.1; occupant load and occupancy classification are determined under the Building Code. [BC §303.1.3, PASSAGE_ID d8c72b84-e4cc-4141-83a4-1cdfeb56c5cc; PC §403.1, PASSAGE_ID 6815fd26-f519-4caf-b0be-f2ed5d913630; PC §403.1, PASSAGE_ID 982771a8-9502-458a-854c-c29dd2ba0e30]

If an Assembly fixture calculation is used, the supplied calculation rule is: determine the Building-Code occupant load; divide it equally between sexes; apply the applicable Table 403.1 fixture ratio(s) for each fixture type to each sex; and round fractional fixture results up. For multiple occupancies, first sum the fractional results for each occupancy and then round up. The equal sex split need not be used where approved statistical data supports a different sex distribution. A separate supplied rule says Group B office calculations use the total occupant load on a given floor, but the evidence does not establish that this multipurpose room is a Group B office occupancy.
