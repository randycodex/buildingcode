For an intermittently operated mechanical-ventilation system in an enclosed parking garage, MC 404.1 requires automatic operation by carbon monoxide detectors used **in conjunction with nitrogen dioxide detectors**. Carbon-monoxide detectors only omit the required nitrogen-dioxide detection, and a 35 ppm CO start point is higher than the stated 25 ppm CO trigger.
