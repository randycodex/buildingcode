Yes. If the room qualifies under the stated accessory-assembly rule—assembly use, accessory to another occupancy, and an occupant load under 75—it is classified as Group B or as part of the principal occupancy. The normal starting point is therefore the Group B fixture requirements in Table 403.1.

But the code expressly permits an alternative: fixtures for that accessory assembly room may instead be calculated using the Assembly-occupancy requirements. That permission does not make Assembly fixture ratios mandatory, so a normal Group B calculation remains permitted. The supplied text does not include Table 403.1, so it does not establish the resulting fixture counts under either method.

The separately supplied Plumbing Code permission is limited to a building or nonaccessory tenant space; it should not be treated as independent authority for this accessory room. The direct authority for the accessory-room Assembly option is BC 303.1.3.

If calculating fixtures, divide the occupant load equally between sexes, apply the applicable Table 403.1 ratios, and round fractions up; a different sex distribution may be used only when approved statistical data supports it.
