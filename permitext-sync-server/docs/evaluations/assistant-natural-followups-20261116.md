# Natural follow-up evaluation — November 16, 2026

Ran real local Luna conversations using synthetic projects: mechanical duct/fire/smoke dampers, cafe toilet fixtures, zoning cellar/basement floor area, accessibility of a roof terrace/entrance, and gas-furnace clearances. Each has an initial natural question and three follow-ups. Cases include “that one,” “down there,” a smoke-barrier correction, a curb-level correction, a separate entrance question, an explicit return to the roof, and requests for the provision or table cited earlier.

The final 20-turn matrix completed all requests and preserved the intended subject. An additional four-turn cafe regression passed after historical citation labels were separated from current-turn IDs. The adjacent JSON combines the latest result for each topic, with actual timings, resolved intent, evidence identities, recall/search actions and answer text. All displayed library citation identities resolved to persisted evidence; all external links matched retrieved web records. Topic regex checks are only screening: subject continuity, qualifications, code-family choice and recalled-source use were also inspected in the actual answers and traces. These checks do not establish exhaustive coverage or professional legal accuracy.

Three issues were found and fixed generally:

- Recalling a canonical section containing unselected diagrams failed while creating the immutable snapshot. Recall now restores the original excerpt only if its paragraphs still occur in the current same-edition text. Only previously selected figures are hydrated and integrity-checked. A stale excerpt or missing selection is reported as unavailable so research can continue. Complete table grids, blank/spanning headers and footnotes have dedicated integrity tests.
- Source deduplication by section ID alone could hide a new relevant excerpt from a section already recalled. Distinct passage text can now be returned separately, retaining current-turn citations.
- A prior answer's citation number was copied into a new answer without recalling that provision. Historical citation labels now include their prior-turn context and cannot be mistaken for current source markers. The targeted four-turn regression had no unverified citation markers after this change.

A general prompt clarification also tells Luna to choose governing source families using relevant project attributes rather than accepting the prior answer's codebook choice as authoritative, and to preserve the conditional status of prior assistant examples. The gas-equipment regression then retrieved the Fuel Gas Code directly. No code-topic/section-specific implementation was added.

For the combined latest results, completed follow-up answers had a median of about 10 seconds and a slowest result of about 29 seconds. Context resolution added a median of about 3 seconds. Most follow-ups completed in 13 seconds. These are measured local samples, with two independent synthetic conversations evaluated concurrently, not a latency guarantee or controlled causal benchmark. The slower roof follow-up performed additional source research. No extra reviewer or verification model call was added.

The first exploratory matrix exposed two snapshot failures and stopped those chats early; these failures are not counted as passing. Subsequent matrices and the targeted citation regression passed. The original reviewed Assistant and production rollout were not changed. Local cumulative testing used the existing $7 ledger, never a reset budget.
