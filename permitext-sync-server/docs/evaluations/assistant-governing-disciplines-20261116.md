# Governing disciplines — local evaluation, November 16, 2026

The previous experimental path let the first question start keyword searches without an explicit map of independent governing obligations. Follow-up interpretation preserved conversational meaning, but did not systematically nominate cross-disciplinary obligations. Source-family prompt guidance helped intermittently: a baseline rerun found the residential accessible-route requirement but missed the complete common-space/recreational scoping analysis. Broad repeated searches also caused request-size failures.

Implementation now combines reference resolution with a bounded research plan on first questions and follow-ups. It derives potentially deciding obligations from current project users, occupancy, activity, common/private use and work status. The plan is grounded in actual authorized library chapter headings. A general lexical check maps those expanded obligations back to chapter titles, supplementing mistaken model chapter IDs; it does not route elevator/roof words to a hardcoded accessibility rule. A second lightweight selection reads actual governing candidates from the selected chapter hierarchy. Reads include parent and adjacent sibling context, labeled for an applicability check. Headings and previews are never treated as the statutory text.

A direct-read tool accepts actual authorized section IDs or current discovery candidate IDs. Search results are compact previews, and library citations are accepted only after actual text is read. Complete code text, tables and edition identities use the existing source binding and immutable snapshots. Failed/missing candidate sections are returned as unavailable rather than aborting supported research. Long sections require a targeted search for a complete relevant passage; they are not silently cut into authoritative fragments. Recent candidate previews are retained for selection; old previews and repeated full source bodies are removed from the model transcript. Read evidence remains available once. Grouped citations also pass the read-identity check. The reviewed Assistant and hosted rollout are unchanged.

Tests: nine synthetic cross-disciplinary turns across a shared residential roof, cellar laundry, courtyard dining, bedroom skylight and a narrow drainage control, plus eight prior mechanical/plumbing conversation turns. All 17 final cases completed with valid identities for actually read sources and retained the intended subject. A repeated four-turn roof/control validation also passed. Initial development attempts exposed context-size, incomplete-section and mistaken-ID errors; those attempts are not counted as passing. Full output and measured timings are in the adjacent JSON.

The first roof question retrieved and read BC 1107.3, 1107.4 and 1110.2.2 before answering. The response leads with the common resident-space accessible-route obligation and the practical need for elevator service absent another compliant route. Separate tests distinguished residents-only common use from private-unit space and explained that stairs do not replace accessible access. The recreational-facility counting qualification appeared explicitly in one repeated roof run and follow-ups; wording varied across runs. Reading all governing sources is an improvement, not proof that every response will explain every exception perfectly.

Other cases discovered accessibility and shared-facility requirements for laundry, egress/access/zoning concerns for courtyard dining, and light/ventilation requirements for a bedroom. The narrow drain question remained focused on Plumbing Code provisions. Existing follow-ups retained sprinkler exceptions, the correction from a corridor to a smoke barrier, shared staff/customer toilet use and requests for the governing provision. No evaluation case or section-number list is imported by the implementation.

Latency increased materially. In final samples, initial research generally took about 10–52 seconds and follow-ups about 18–30 seconds; another repeated roof answer took 64 seconds while checking official Chapter 11 online. The compact source transport removed the observed request-size failures, but chapter planning/navigation and wider research add work. This has not been established as production-ready or an exhaustive code analysis. Luna was retained; no stronger-model comparison or upgrade was performed in this task.
