04 / A FEW DETAILS

Before you
begin.

What is Permitext?

Permitext is a workspace for NYC code research. It brings code reading, search, saved references, and Research tools into an experience designed around working with source material.

Can I explore the web workspace without an account?

Yes. You can browse codes, read provisions, follow references, and search without signing in. Account features and plan details are explained in the workspace.

How does the iOS app fit in?

Permitext also has a native iOS app for browsing and reading codes, searching provisions, and returning to saved references. The web workspace provides a wider layout with adjacent columns. Features and access can differ between platforms.

A public App Store download link is not listed on this page yet.

Which code edition should I use?

The appropriate edition depends on your project and the applicable rules. Check the code, edition, amendments, and source information in the library. A historical edition is not automatically the governing edition for your work.

Does Permitext provide official code interpretations?

No. Permitext is an independent research and workspace tool. Review original sources and seek the appropriate professional or agency determination for your project.
