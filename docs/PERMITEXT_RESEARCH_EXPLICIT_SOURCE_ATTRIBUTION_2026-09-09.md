# Explicit Zoning source attribution

The retained ZR-06 provider draft put two provisions' rules into one supporting point but bound that point only to ZR 42-193. Its second sentence explicitly credited the historical-facility treatment to ZR 42-192. Correct citations elsewhere in the answer did not connect that claim to its supporting source.

The local Zoning compiler now rejects this mismatch as `EXPLICIT_ZONING_RULE_SOURCE_NOT_BOUND`. It checks direct numbered ZR subjects in supporting-point headings and explanations, including coordinated subjects and negative rule statements. It resolves those subjects only against supplied ZR section identities. Canonical deterministic context now includes each passage's code prefix, and the generation instructions tell the model to bind every explicitly credited provision to its point or split mixed-source points.

This is a bounded attribution check, not proof that a passage entails a claim. It does not certify edition selection, completeness, arbitrary paraphrases, unnamed authorities or absent sources. A provision merely incorporated or mentioned by another source does not automatically become a separate rule attribution. Semantic verification and existing source checks retain those responsibilities.

These contrast edits are checker tests, not newly generated answers or professional approval.
