# Simplified Research writer validation — 2026-10-06

## Change

One general writing policy replaces the repeated drafting rules and provision-specific hints in normal answers and repairs. The writer receives the same source text, table structures, facts, full zoning plan, deterministic context and repair feedback as data. Citation/schema validators, retrieval, material-scope review, semantic verification and freshly checked revisions remain active. Official site investigation from the earlier local fix is included so linked project-address questions obtain parcel evidence before asking for documents.

The version is `20261006-direct-writer-v1`. An offline audit of the actual request builder across the frozen 80-case evidence packets measured median instruction text falling from 33,148 to 3,577 characters (89.2%). Model, effort, output allowance and `store:false` were preserved; every supplied source text and full plan survived. This audit makes no generated-answer accuracy claim.

## Live case

A temporary local account/project at 155 E 182nd Street, Bronx used real NYC records and gpt-6-luna with supporting web search disabled and a $0.50 cap per isolated run. Existing user history and hosted data were untouched.

The first run failed verification: a targeted citation repair dropped the earlier correct conditional result and 100-foot qualification. The repair path was corrected to retain the general writer policy alongside the bounded edit format. Review limits and all substantive checks were preserved.

The subsequent run returned HTTP 200, `mode=openai`, `verification.pass=true` after a full repair and fresh review. Its final answer begins: “Yes for the mapped tax lot, and preliminarily yes under the Zoning Resolution if the project’s zoning lot is the same as tax lot 2031630001 and the two mapped faces are the legal street lines.” It cites official PLUTO/DOF URLs and ZR 12-10, explains the approximate 90-degree mapped angle, distinguishes tax lot from zoning lot, and preserves the 100-foot extent rule.

That successful run used four provider calls and about 57 seconds. Estimated provider cost was $0.013900; the preceding failed run cost an estimated $0.022266. Together with the earlier 80-case comparison estimate of $1.010160, the exercise is approximately $1.046326 under the user's $10 initial ceiling. Estimates use the existing evaluation pricing; actual billing was not independently inspected. One live site case is not general acceptance or a promise that every answer matches ChatGPT.
