# Research section references and complete definitions

The last five numbered cases (ZR-03, ZR-06, ZR-09, ZR-19, ZR-20) were blocked before provider dispatch because the evaluation driver turned section IDs into full-text highlights. Appendix J then required a visual selection that the author had never made, while the enormous 12-10 section exceeded the passage limit. These were input failures, not unsuccessful model answers.

The local HTTP API now accepts an explicit `section_reference` selection mode. It binds the current canonical section and edition without fabricating a highlighted passage, a selected map, a saved passage, or visual-review confirmation. Mixed requests claiming those properties are rejected. Legacy exact-passage validation and its visual-review gate remain active. A missing parcel can receive the existing conditional source explanation, with the property determination unresolved; missing historical enacted text still blocks dispatch. No client UI is wired to the new mode in this change.

Offline inspection exposed two further failures. A full `canonicalText` field carried by HTTP pins could overwrite a targeted excerpt. Also, the opening of an entire referenced definitions section could contaminate definition ranking. The assembler now preserves the selected excerpt in both text fields, excludes unselected section prefixes from query context, and follows cross-references from the selected definitions rather than every unrelated entry in the complete section.

Definition retrieval now preserves the complete zoning-lot ownership pathways and the complete basement, cellar and floor-area definitions when those dependencies fit the budget. Section 27-111's paragraph-label format is parsed as complete definitions, retaining the UAP increase condition and its closing exception. The calculation path permits two definition sources so that 27-111 cannot crowd out 12-10. The definition path's total character ceiling is 14,000 with a 12,000-character per-source ceiling; the calculation path retains its existing total ceiling. These are retrieval changes, not injected expected answers.
